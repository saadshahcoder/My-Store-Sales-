# 📊 My Store Sales — Excel Sales Analytics Dashboard

An interactive **Microsoft Excel sales and order analytics dashboard** designed to transform retail sales data into clear, business-focused insights.

The dashboard uses **PivotTables, PivotCharts, and Slicers** to analyze sales performance, order trends, customer demographics, order status, sales channels, and state-wise sales.

---

## 📌 Project Overview

**My Store Sales** is a retail sales analytics project created in Microsoft Excel.

The objective of this project is to transform raw sales and order data into an interactive dashboard that allows users to quickly understand:

- Where sales are being generated
- Which sales channels contribute the most orders
- How sales are distributed between men and women
- Which states generate the highest sales
- How orders vary across age groups and gender
- What percentage of orders are delivered, cancelled, returned, or refunded
- How sales and order volumes change throughout the year

The dashboard allows users to interactively filter the analysis using **Channel, Category, and Month slicers**.

---

# 🎯 Business Problem

Retail businesses generate large amounts of sales and order data, but raw data alone does not provide an easy way to identify important business patterns.

The key challenge is:

> **How can raw sales and order data be transformed into an interactive dashboard that helps management quickly understand sales performance, customer demographics, order status, and sales-channel performance?**

This project addresses that problem by converting the underlying data into a visual and interactive Excel dashboard.

# 📊 Dashboard Features

## 1. Sales: Top 5 States

The dashboard identifies the five states with the highest sales:

| State | Sales |
|---|---:|
| Maharashtra | 2.84M |
| Karnataka | 2.51M |
| Uttar Pradesh | 2.01M |
| Telangana | 1.63M |
| Tamil Nadu | 1.59M |

This helps identify the geographic markets generating the highest sales within the displayed data.

---

## 2. Orders vs Sales

The combination chart compares:

- Monthly sales amount
- Monthly order count

This allows sales performance and order volume to be viewed together across the year.

The chart helps identify periods where sales and order volumes increase or decrease.

---

## 3. Orders: Age vs Gender

The dashboard compares orders across three age groups:

- Adult
- Senior
- Teenager

and separates them by:

- Men
- Women

Displayed distribution:

| Age Group | Men | Women |
|---|---:|---:|
| Adult | 15.59% | 35.08% |
| Senior | 5.74% | 13.25% |
| Teenager | 9.25% | 21.08% |

This provides a demographic view of the order distribution.

---

## 4. Order Status

The dashboard shows the distribution of orders by status.

Displayed results:

| Order Status | Share |
|---|---:|
| Delivered | 92% |
| Cancelled | 3% |
| Returned | 3% |
| Refunded | 2% |

The visualization helps understand the overall order fulfillment and post-order status distribution.

# 🔎 Key Business Insights

Based on the dashboard:

### 1. Women contribute a larger share of sales

Women account for **64% of sales**, compared with **36% for men**.

This indicates that the sales represented in this dataset have a higher contribution from women customers.

# 🎛️ Interactive Dashboard

The dashboard contains three main slicers:

### Channel
Filter the dashboard based on sales channel.

### Category
Filter the dashboard based on product category.

### Month
Filter the dashboard by month.

These slicers allow users to interact with the dashboard instead of manually analyzing the underlying data.
